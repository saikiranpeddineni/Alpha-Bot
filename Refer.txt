How to run it
.\install.ps1    # once (or double-click install.cmd)
.\start.ps1      # → http://127.0.0.1:8742 → press ▶ Start
Demo mode needs zero configuration. For real market data, add free Alpaca keys to .env and switch to Paper. Live trading is deliberately double-gated: ENABLE_LIVE_TRADING=true in .env plus typing LIVE in the confirm dialog (enforced server-side).

Architecture in one paragraph
A FastAPI app hosts an async TradingEngine tick loop: data poll → indicator enrichment → regime detection → four strategies (orb, vwap_reversion, momentum, rsi2_reversion) → AI signal pipeline (locally-trained gradient-boosting gate + regime weighting + conflict resolution) → risk manager (ATR sizing at 0.5% equity risk, daily-loss halt, drawdown kill switch, loss-streak cooldown, EOD auto-flatten, PDT guard) → pluggable brokers (built-in fill simulator / Alpaca with server-side brackets). The backtester replays history through the identical stack with next-bar-open fills, so what you test is what trades. Everything persists to local SQLite; the React terminal consumes one multiplexed WebSocket.
