# Workspace Rules

## Git Workflow Best Practices
- **No Direct Main/Master Commits**: Under no circumstances should commits or pushes be made directly to the `master` or `main` branches.
- **Feature Branching**: Always create a descriptively-named feature branch (e.g., `feature/description-here`) for all modifications and new features.
- **Commit Isolation**: Commit all code changes, test updates, and bug fixes to the feature branch.
- **Pull/Merge Request**: Present the finished branch and its verification results to the user, allowing them to explicitly approve, merge, or pull the feature branch.
